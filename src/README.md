# A-List app source

Next.js source for the mix library, audio player, chapters, and podcast feed.

From the Whiskey repository root, start local development with:

```bash
bun run dev:a-list
```

Open <http://a-list.localhost:3003>. This command loads development secrets from Infisical.

See [the A-List README](../README.md) for the data model, builds, and deployment requirements. The app uses OpenNext on AWS, not Vercel.
